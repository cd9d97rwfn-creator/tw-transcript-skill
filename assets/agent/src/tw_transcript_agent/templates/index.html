自行部署與 GitHub 設定

分享包內的 assets/agent 是完整網站程式。依 README 建立環境，設定自己的 OPENAI_API_KEY 與 APP_PASSWORD，再啟動 run_web.py，或用 Dockerfile 部署到 Railway。你的 API 費用由你自己的帳戶負擔。

要顯示原始碼連結，設定 GITHUB_REPO_URL 為自己的 GitHub 儲存庫 HTTPS 網址。此連結不會把音訊或逐字稿上傳 GitHub；請勿提交 .env 或 output 資料夾。
