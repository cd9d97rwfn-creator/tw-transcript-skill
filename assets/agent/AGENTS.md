# 課程逐字稿交付

使用者要求課程轉錄包含專有名詞校稿，不能把簡轉繁當作校稿完成。

- 每堂檢查校名、系所、機構、人名、理論、學派、方法、量表、書名及英文拼寫。先看原始逐字稿上下文，再核對講者／學校／學會／作者／出版者的來源；必要時回聽或核對使用者提供的投影片。
- 使用 `resources/course_terms.json` 的共用規則。CLI 預設 `--term-profile shared`；既有時間戳稿用 `python3 scripts/proofread_course_terms.py <輸出資料夾> --profile shared`。
- `lesson5`、`lesson6`、`lesson7` 分別僅限 2026-10-09 陳雪均第五堂、2026-10-16 黃天豪第六堂及 2026-10-23 陳質采第七堂，不能因新課也談榮格或催眠就套用。`lesson8` 僅限 2026-10-30 耿一偉第八堂。新課先做獨立核對，再新增有來源、有限定範圍的規則。
- 「意向／意象」「自信／自性」「融合／榮格」「疫情／移情」「情節／情結」等有多種正常意義的詞，禁止跨課無條件取代。
- 來源能證明正式拼寫，不能證明錄音實際說了什麼。不用學術常識改寫講者主張、否定詞、年代或引文。未確認的保留原文並列時間點／候選詞，不能冒稱已回聽。
- 同步修正 TXT 與 SRT；保留原始辨識稿、原始分段 JSON、校稿前版本、逐筆修改及來源紀錄。驗證時間戳、段數不變，原始稿雜湊不變，更新交付雜湊。
- 最終清楚標示「專有名詞校稿版」與尚未逐句聽校的範圍；持續保留未決疑點。
