目前不提供 SRT／VTT 或說話者辨識。分段 JSON 不是逐句時間戳；共用術語修正也不等於逐句聽校。

START WITH YOUR OWN WORKSPACE

把完整服務部署到你的環境。

  1. 下載或 Fork GitHub 專案。
    網站程式在 assets/agent 資料夾。
  2. 設定自己的金鑰與密碼。
    將 .env.example 複製為 .env，填入自己的 OPENAI_API_KEY 與至少 20 字元的 APP_PASSWORD。
  3. 選擇本機或 Railway。
    本機需 Python 3.11+ 與 FFmpeg；Railway 以 assets/agent 為根目錄，使用 Dockerfile 並掛載 /data 持久磁碟。
  4. 登入你自己的轉錄網站。
    選擇音檔、開始轉錄，完成後下載。持有相同網站密碼的人會共用資料與部署者的 API 額度。

這個 Netlify 介紹站不執行轉錄服務；Python／FFmpeg 背景程式請在本機或適合的伺服器環境執行。

開始前，你可能想知道。

我需要付費嗎？

下載分享包不需要提供金鑰。實際轉錄使用你自己的 OpenAI API 帳戶，可能產生用量費用；自行部署也可能產生主機費用，依各服務方案計算。本網站不向你收取轉錄費用，也不提供作者的 API 額度。

可以把 Skill 交給 AI 助手使用嗎？

可以。專案根目錄的 SKILL.md 包含轉錄與來源核對規範，附帶程式位於 assets/agent。依你使用的助手支援方式載入 Skill，並閱讀部署與輸入限制。

轉完就是已經校稿完成嗎？

不是。程式只套用已核對的共用術語規則，未完成每堂課的獨立來源核對，也未逐句聽校。人名、否定詞、年代、引文與多義詞仍需核對。正式拼寫來源不能證明錄音實際說了什麼。

音檔與文字會存在哪裡？

這個介紹站不收取音檔或金鑰。自行部署後，音訊會送至 OpenAI 進行轉錄；轉錄成功後程式刪除伺服器音檔，失敗工作保留音檔以便重試。逐字稿與紀錄保存在你自己的服務中，需自行管理保存與備份。
